第一大陆：鲁罗罗

从领取初始宝可梦开始，完成八枚徽章与联盟挑战。

第一枚徽章：谷神星

  1. 在谷神星道馆前向叔叔领取初始宝可梦。
  2. 沿北面的道路前往莲叶市，在城市右侧完成击败罪犯的事件。
  3. 进入警局推进对话，领取宝可梦图鉴。
  4. 返回谷神星，挑战叔叔的道馆。

在呼吸森林击败表亲，可以取得 HM01「居合斩」。

相关地图 谷神星 莲叶市 呼吸森林

第二枚徽章：虫虫镇

  1. 沿甲虫道路前进，经过蘑菇山，到达虫虫镇。
  2. 进入城镇北面的奇迹森林，完成初次剧情。
  3. 回城与馆主交谈，再返回森林寻找治愈师。
  4. 完成治愈师相关事件后回道馆挑战。
相关地图 甲虫道路（分区 1） 虫虫镇 奇迹森林（南） 奇迹森林（北） 蘑菇山（分区 1）

第三枚徽章：宾利市

  1. 到达宾利市后，先去城市右侧的瘟疫之湖完成事件。
  2. 前往水处理设施，完成设施内剧情。
  3. 依次挑战冯弦、宫羽、米利的道馆。
  4. 前往宾索的道馆，再寻找并击败城里的三个小丑。
  5. 击败三个小丑后，挑战宾索，取得本阶段徽章。

与城中的女警交谈可以取得 HM06「碎岩」；剧院和教堂的训练家战斗有额外奖励。

宾利市设有饲养屋。小丑和道馆位置可在「查看地图」的宾利市总图中查看。

相关地图 宾利市（分区 1） 宾利市（分区 2） 瘟疫之湖（东岸地图） 瘟疫之湖（西岸地图）

第四枚徽章：碎岩市

  1. 前往碎岩市。
  2. 探索狩猎地带，取得 HM04「怪力」。
  3. 挑战摇滚之家，再挑战道馆。
相关地图 碎岩市 狩猎地带（分区 1）

第五枚徽章：水晶市

  1. 返回莲叶市，从城市右侧的岩石区域通过，穿过洞穴前往巴伐利亚。
  2. 沿冰冻之路到达水晶市。
  3. 进入教堂击败神父，再完成洞穴内的战斗。
  4. 挑战水晶市道馆。

原指南另列酒吧与劲敌战斗；城中的蘑菇爱好者可帮助回忆招式。

相关地图 莲叶市 巴伐利亚 冰冻之路 水晶市

第六枚徽章：天照市

  1. 给宝可梦学会本作 HM05「挖洞」。
  2. 在朱迪山寻找深褐色地洞，使用挖洞进入地下区域，前往天照市。
  3. 进入铁矿，完成矿区内的剧情。
  4. 挑战天照市道馆。

在天照市与莫甘娜再次见面，推进剧情对话可获得 HM02「飞翔」。她会提到你此前在黑暗之路救过她。

天照市有遗忘招式的 NPC，也有出售各类精灵球的商店。

相关地图 朱迪山（南段） 朱迪山（北段） 天照市（分区 1）

第七枚徽章：大西洋市

  1. 回到大西洋市，此阶段道馆会开放。
  2. 击败馆主取得徽章。

城中另有付费钓鱼区域和大型商店。

相关地图 大西洋市（分区 1）

第八枚徽章：金国市与隔离区

  1. 到达金国市，与照井龙局长和馆主泰山交谈，接下调查宾利市下水道的任务，局长会赠送 HM03「冲浪」。
  2. 返回宾利市，在下水道入口使用 HM05「挖洞」进入，击败其中的敌人。
  3. 到玉米道路的关卡触发事件，再去布宜诺市寻找 Ábaco 教授。
  4. 前往马黛茶洞窟取得果实，把果实交给奇迹森林的治愈师。
  5. 返回道路关卡继续剧情，进入隔离区和发电设施。
  6. 与书架互动寻找机器人密码，击败敌人，完成基格尔德事件。
  7. 完成上述剧情后挑战道馆。

布宜诺市教堂另有战斗与奖励。

相关地图 金国市 宾利市（分区 1） 玉米道路（东段） 玉米道路（西段） 布宜诺市 马黛茶洞窟（洞内区） 奇迹森林（南） 隔离区

鲁罗罗联盟与赫拉克勒斯的五项任务

  1. 穿越亚马逊森林，接受赫拉克勒斯的任务。
  2. 任务一：进入旁边的建筑，与地上的污物互动，完成清理。
  3. 任务二：在亚马逊森林寻找空地，击败亚马逊战士。
  4. 任务三：从巴伐利亚右侧登山，到小森林中击败或捕获 Hydra。
  5. 任务四：与金国市馆主交谈。
  6. 任务五：分别与瘟疫之湖的雷公、甲虫道路地下的炎帝、水晶市的水君战斗。然后前往马黛茶洞窟顶部挑战凤王。
  7. 五项任务完成后，挑战鲁罗罗联盟。

三只传说宝可梦不要求全部捕获，与它们战斗即可。

相关地图 亚马逊森林（东段） 巴伐利亚 金国市 瘟疫之湖（东岸地图） 甲虫道路（分区 1） 水晶市 马黛茶洞窟（洞内区） 鲁罗罗联盟

第二大陆：八把钥匙

钥匙剧情是第二大陆的主要转折阶段；部分城市建筑会暂时关闭。

第一把钥匙：华夏市

  1. 从金丝雀市经过水豚森林南侧与猛禽道路，前往卡纳市。
  2. 在实验室前触发事件，得知需要收集八把钥匙。
  3. 返回第一大陆虫虫镇北面的奇迹森林，完成事件，获得秘传机和超级石。
  4. 回卡纳市，沿左侧路线穿过水路、山路和森林，抵达华夏市。
  5. 击败第一把钥匙的守护者。

华夏市的特殊塔为可选挑战，城内还有大型商店。

相关地图 金丝雀市 水豚森林 猛禽道路（西段） 卡纳市（城镇 2） 奇迹森林（南） 华夏市

第二把钥匙：凤凰岛

  1. 前往凤凰岛，击败第二把钥匙的守护者。
  2. 返回金丝雀市，寻找 Rambo 交谈。
  3. 进入植物园内部的敌方前哨站，完成事件。

植物园宿舍是可选事件。原指南建议第二大陆使用飞翔时站在道路上。

相关地图 凤凰岛 金丝雀市

第三把钥匙：霍兰迪亚市

  1. 从复兴市北面进入沼泽，救出 Purpeia，取得秘传机。
  2. 穿过沼泽，抵达霍兰迪亚市。
  3. 击败第三把钥匙的守护者。
相关地图 霍兰迪亚市 复兴市

第四把钥匙与救治帝牙卢卡

  1. 回到复兴市，击败第四把钥匙的守护者。
  2. 地震后进入面前的门，击败内部敌人；最后两名敌人战后，帝牙卢卡需要治疗。
  3. 回奇迹森林与治愈师交谈，取得卡纳市热气球通行证。
  4. 乘热气球到另一地区，寻找教授并取得果实。
  5. 带着果实再次找治愈师，让他制成药。
  6. 返回帝牙卢卡所在处，完成治疗事件。

拿到果实后必须再与治愈师交谈，不能直接回帝牙卢卡处。
